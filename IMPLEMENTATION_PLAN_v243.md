# План реализации LIGA OS v2.4.3: Премиальные тогглы, Живые кнопки, Шелковистый скролл и Голосовой консьерж

## 1. Контекст и замечания владельца
1. **Тогглы в «⚙️ Настройки LIGA OS»:** Выглядят кустарно как сплошные бежево-желтые «сосиски» без бегунка. В коде `content: \'\';` с экранированными слешами ломало CSS псевдоэлемента `::before`.
2. **Сбой скролла на экране «📜 ИСТОРИЯ ОБЪЕКТА»:** Скролл застревает или сбоит из-за синтаксической ошибки в CSS (лишняя скобка на строке 980), тройного `overflow-x: hidden` и отсутствия `touch-action`.
3. **Кнопка `+ Платеж`:** Сливается с информационной плашкой «Аванс получен». Глаз не считывает ее как интерактивную кнопку.
4. **Главная рутина мастера (Голосовой ввод, навигация, подтверждения):**
   - Голосовые команды должны сопровождаться естественным русским голосом системы («Открываю смету...», «Открываю 16 бар...») и золотой подсветкой открытого раздела.
   - При диктовке расхода система выводит крупную модальную карточку быстрого подтверждения с тремя кнопками для пальца и голосовым подтверждением «Да»:
     `[ ✅ Подтвердить (или скажите «Да») ]`
     `[ 🏢 Другой объект ]`
     `[ ✕ Отмена ]`

## 2. Совет трех экспертов
- **Архитектор:** Исключить синтаксические опечатки в CSS, выстроить единую систему визуального affordance для интерактивных элементов, нормализовать модель скролла viewport и внедрить двусторонний диалог голосового ассистента.
- **Разработчик:** Использовать чистый CSS3 и Vanilla JS ES6+. Подключить Web Speech API / SpeechSynthesis с выбором естественных русских нейросетевых голосов.
- **Инженер по качеству (QA):** Разработать автотесты Playwright на рендеринг бегунка тогглов, кликабельность кнопки платежа, скролл истории и карточку голосового подтверждения. Прогнать полную регрессию (65+ тестов).

## 3. Поэтапный план реализации

### Этап 1: Премиальные переключатели (Toggle Switch)
- Файл: `css/style.css`.
- Заменить `content: \'\';` на валидный `content: "";`.
- Состояние OFF: матовый титановый трек `background: rgba(255, 255, 255, 0.12); border: 1.5px solid rgba(255, 255, 255, 0.22);` и контрастный круглый бегунок 18px с мягкой объемной тенью.
- Состояние ON: золотой градиент `linear-gradient(135deg, #F3E7C4 0%, #D4AF37 50%, #AA771C 100%)`, теплое свечение `0 0 12px rgba(212, 175, 55, 0.5)` и смещение бегунка вправо на 18px.

### Этап 2: Шелковистый скролл и благородный скроллбар (Liquid Scroll Engine)
- Файл: `css/style.css`.
- Удалить лишнюю закрывающую фигурную скобку `}` на строке 980.
- Настроить `html { overflow-y: scroll; scroll-behavior: smooth; }`, `body { overflow-x: hidden; touch-action: pan-y pinch-zoom; }`, `.app-container { overflow: visible; }`.
- Внедрить глобальный тонкий скроллбар Swiss Titanium & Gold (`::-webkit-scrollbar` 6px с золотистым градиентом ползунка).
- Проверить `#screen-history`, `.timeline-container` и гарантировать непрерывную прокрутку ленты событий.

### Этап 3: Живые кнопки действий мастера (Affordance & 3D Tactile Buttons)
- Файлы: `css/style.css`, `index.html`.
- Создать класс `.btn-action-trigger` (объемный градиент, верхний световой блик `box-shadow: inset 0 1px 0 rgba(255,255,255,0.25)`, тактильное продавливание `:active`).
- Переработать кнопку `+ Платеж` (`#btn-open-payment`) на дашборде: выразительный изумрудный неон, иконка `💳 + Внести платеж`, физический объем.
- Переработать кнопки `+ Новый объект` (`#btn-open-add-site`), `+ Событие` (`#btn-open-add-event`), `+ Выплата`, `+ Оборудование`.

### Этап 4: Устранение главной рутины мастера (Голосовой консьерж + Карточка подтверждения)
- Файлы: `index.html`, `js/app.js`.
- Расширить словарь голосовых интентов (смета, опрессовка, гидрострелка, касса, склад, история, базар).
- Внедрить метод `speakVoice(text)` с подбором естественного русского голоса (`Natural`, `Google`, `Neural`).
- При голосовом переходе: озвучивать действие («Открываю смету объекта Mirabad Avenue») и подсвечивать раздел золотым импульсом `.element-spotlight-pulse`.
- При голосовой диктовке закупки («Купил коллектор FAR за 1.8 млн»):
  * Выводить крупную карточку экспресс-подтверждения `#voice-confirmation-card`;
  * Озвучивать вопрос: «Записать покупку коллектора FAR на 1 800 000 сум?»;
  * Предлагать кнопки для пальца: `[ ✅ Подтвердить (или скажите «Да») ]`, `[ 🏢 Другой объект ]`, `[ ✕ Отмена ]`;
  * При слове «Да» или тапе на кнопку — сохранять покупку, списывать из базарного кармана мастера и голосом подтверждать запись.
