# План модернизации LIGA OS: Элитный мировой дизайн, реестр контактов, звуковой фидбек и устранение недочетов

## Обзор задачи
Мастер Улугбек Хакимов поставил ключевые цели для финализации продукта перед сдачей (осталось 2 дня):
1. **Навигационный дефект экрана «Перед стяжкой»**: при нажатии плитки открывается экран технадзора, но вернуться назад нельзя из-за отсутствия крестика закрытия или кнопки возврата.
2. **Искоренение любых следов ИИ**: интерфейс должен звучать строго на профессиональном инженерном языке мастера («Лига Опытных Мастеров», стандарты DIN 1988, СП, экспресс-аудит по экспертным правилам), никаких упоминаний «AI», нейросетей или ботов.
3. **Элитный, дорогой вид мирового уровня**: переход от базовых неоновых карточек к премиальному стилю **Dark Titanium & Champagne Gold** (матовый титан, полированная латунь, ультратонкий стеклянный каркас с внутренним свечением `inset`, выверенная швейцарская типографика).
4. **Звуковые уведомления со смыслом**: благородный офлайн-звук (Swiss Audio Engine на Web Audio API) для подтверждения критических операций (успешная опрессовка 16 бар, фиксация этапа, голосовой ввод) без внешних mp3-файлов.
5. **Бизнес-книга контактов LIGA OS**: отдельный реестр клиентов, дизайнеров и подрядчиков мастера с постоянным ID, привязкой нескольких телефонных номеров, адресов и полной историей объектов за 10 лет.

## Совет трех экспертов (Council of Experts)

1. **Архитектор**:
   - На экранах вторичных разделов (`screen-checklist`, `screen-materials`, `screen-finances`, `screen-estimate`, `screen-history`) внедряется единая представительская плашка возврата: кнопка `← Назад к объекту` и крестик `&times;`, плавно возвращающие пользователя на дашборд через `window.app.switchScreen('dashboard')`.
   - В схему IndexedDB добавляется хранилище `contacts` (постоянный ID контакта, ФИО, роль, текущий и исторические телефоны, адреса, привязанные объекты).
   - В звуковом движке используется чистый Web Audio API (`AudioContext`) с синтезом синусоидальных гармоник — это гарантирует 100% офлайн работу и нулевой вес.
2. **Разработчик**:
   - Полная зачистка DOM и JS от терминов `AI` и замена их на канонические инженерные понятия Лиги Мастеров.
   - Обновление CSS-палитры: введение глубоких титановых тонов (`#0a0e16`, `#131b28`, `#1a2436`), благородного матового золота (`#d4af37`, `#c59b27`) и микро-анимаций.
   - Внедрение 4-й подвкладки в таб «История»: `👥 Контакты Лиги`.
3. **Инженер по качеству (QA/Tester)**:
   - Проверка возврата с экрана стяжки по кнопке назад и по крестику.
   - Проверка синтеза звука в Playwright без сбоев и ошибок в консоли.
   - Проверка реестра контактов: создание, редактирование телефона, сохранение истории объектов.
   - Разработка нового автотеста `tests/test_contacts_and_navigation.py` (тест №17).
