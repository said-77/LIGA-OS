## 1. СТРОГИЕ ПРИНЦИПЫ И ИСПРАВЛЕНИЕ ОШИБОК ПОЗИЦИОНИРОВАНИЯ (ПО АУДИТУ GPT)

На основе строгого независимого аудита GPT и указаний владельца проекта зафиксированы следующие обязательные правила:

1. **Честность хранения данных и резервного копирования**:
   - Запрещено называть Telegram «вечным, безлимитным и неломающимся облаком».
   - Веб-приложение (PWA) без серверного бэкенда и секретных токенов бота НЕ может автоматически отправить файл в «Избранное».
   - **Утвержденная реальная архитектура**:
     - Приложение генерирует файл резервной копии `liga_backup_YYYY-MM-DD.json`.
     - Вызывается стандартный системный интерфейс `navigator.share({ files: [...] })` (меню «Поделиться» операционной системы смартфона). В этом меню Улугбек сам выбирает Telegram, WhatsApp, Почту или сохранение на диск.
     - Если системный Web Share API недоступен (например, на старых браузерах) — выполняется прямое скачивание файла в загрузки телефона.
     - Запрещено обещать «шифрованные защищенные .liga архивы», пока нет физического шифрования. На текущем этапе используется надежный валидируемый JSON с проверкой структуры, даты и схемы.
     - Запрещено заявлять «восстановление за 2 секунды». Процедура восстановления обязана быть контролируемой: валидация схемы файла, показ модального окна с метаданными (сколько объектов, сколько чеков, дата создания) и явное подтверждение мастером перед заменой данных.

2. **Формирование стоимости и тарифов (Смета)**:
   - Запрещено назначать жесткие коммерческие расценки (например, «1 500 000 сум за санузел») в коде от своего имени. Ценообразование — исключительная прерогатива мастера Улугбека.
   - **Утвержденное решение**:
     - В коде создается прозрачный конфигуратор тарифов (объект `tariffSettings`), доступный для редактирования и калибровки.
     - Стартовые расчетные значения явно маркируются в интерфейсе: `«Базовый ориентир (требует утверждения Улугбеком)»`.
     - Все параметры на экране (санузлы, водорозетки, инсталляции, iBox, трапы, теплый пол) обязаны математически строго участвовать в расчете итоговой суммы либо быть убраны.

3. **Честность документов и паспорта объекта**:
   - Запрещено автоматически писать «Опрессовка 16 бар пройдена, 24 часа без падения давления», если мастер физически не внес акт гидроиспытаний и фото манометра с датой.
   - До момента внесения реальных замеров документ обязан иметь статус **«ЧЕРНОВИК / ИСПЫТАНИЯ НЕ ЗАФИКСИРОВАНЫ»**.
   - Кнопка формирования паспорта честно именуется: **«Печать / Экспорт в PDF»**, так как генерация выполняется через оптимизированный HTML-диалог печати браузера.

4. **Изолированный «Клиентский режим» (Client Presentation Mode)**:
   - Это не просто сокрытие элементов через CSS (`display: none`).
   - Это отдельный безопасный экран/контекст показа, в модель отображения которого физически не передаются внутренние зарплатные долги бригаде, себестоимость материалов с базара и личные заметки мастера.

5. **Честность технологических статусов**:
   - Запрещено называть систему «100% офлайн», если Web Speech API (распознавание речи) или отправка расписок через мессенджеры требуют подключения к сети. Разграничение «Офлайн-база» и «Функции, требующие сеть» должно быть явным.
   - Запрещено называть набор статических правил «AI-Аудитором». Функция должна честно именоваться: **«Инженерный аудит по экспертным правилам»**.

6. **Единственный источник истины**:
   - Единственным источником истины является репозиторий GitHub. Все документы на Рабочем столе — это удобные копии для владельца.
