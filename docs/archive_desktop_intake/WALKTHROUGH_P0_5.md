# Отчет о реализации и верификации задачи P0-5: Честность сетевых и инженерных статусов

## 1. Цели задачи
1. **Искоренение "AI-washing"**: Отказ от вводящих в заблуждение терминов «ИИ-Аналитик» и «ИИ анализирует...» применительно к детерминированным расчетам на основе жестких строительных правил и формул. Переименование инструмента в **«Инженерный экспресс-аудит (экспертные правила)»** со ссылкой на стандарты (DIN 1988, СП 30.13330, гидроиспытания 16 бар).
2. **Прозрачность сетевого статуса**: Четкое разделение компонентов, работающих на 100% офлайн (IndexedDB, расчет сметы, генерация паспорта, локальный бэкап) и функций, требующих сетевого соединения (Web Speech API для распознавания голоса, отправка ссылок цифровых расписок через Telegram/мессенджеры, открытие внешних веб-сайтов).
