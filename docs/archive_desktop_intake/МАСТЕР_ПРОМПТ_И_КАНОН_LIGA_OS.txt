--------------------------------------------------------------------------------
1. МИССИЯ И СУТЬ ПРОДУКТА
--------------------------------------------------------------------------------
НАЗВАНИЕ ПРОЕКТА: «LIGA OS» — Операционная Система Инженерного Мастера
СУТЬ ПРОДУКТА: Автономная мобильная операционная система и персональный цифровой верстак для ведущего инженера сантехники элитного жилья в Ташкенте (Мастер Улугбек Хакимов, «Лига Опытных Мастеров»).

ДЛЯ КОГО ЭТО СДЕЛАНО:
Пользователь — мастер-практик Улугбек. Он работает на реальных стройках (Mirabad Avenue, Tashkent City, Nest One, частные коттеджи). 
У него пыльные руки, он держит смартфон одной рукой на объекте, у него нет времени разбираться в сложных меню, базах данных и бухгалтерских терминах. 

ГЛАВНЫЙ ПРИНЦИП ИНТЕРФЕЙСА:
«ПРАВИЛО ОДНОГО БОЛЬШОГО ПАЛЬЦА И 10 СЕКУНД». 
Любое действие (записать оплату, сфотографировать узел, добавить чек, выдать PDF-паспорт) должно совершаться максимум в 2-3 клика крупными кнопками без клавиатурного набора длинных текстов.

ЧЕМ ПРОДУКТ НЕ ЯВЛЯЕТСЯ:
- Это НЕ сложная громоздкая 1С или SAP.
- Это НЕ шаблонная таблица Excel.
- Это НЕ приложение с кучей ненужных вкладок и мелких полей.

--------------------------------------------------------------------------------
2. ДИЗАЙН-СИСТЕМА И ВИЗУАЛЬНЫЙ СТАТУС (УРОВЕНЬ СОФТА ЗА $50 000)
--------------------------------------------------------------------------------
ЭСТЕТИКА: «Dark Titanium & Gold Glassmorphism» (стиль бортовых систем Bentley / Porsche и закрытых финансовых терминалов).
Когда Улугбек открывает приложение перед состоятельным заказчиком или дизайнером на объекте — у них должно возникать ощущение работы с элитной IT-компанией.

ПАЛИТРА:
- Фон: Глубокий матовый титан (#060911, #0b1120)
- Карточки: Полупрозрачное затемненное стекло с мягким размытием (backdrop-filter: blur(20px))
- Акценты статуса: Теплое полированное золото (#ffd175, #d4a359), неоновый сапфировый циан (#00f2fe)
- Финансовый успех: Изумрудный неон (#00f5a0)
- Долги / Внимание: Рубиновый неон (#ff2a5f)
- Типографика: Премиальные шрифты Unbounded (акценты) + Montserrat / Segoe UI (интерфейс)
- Тактильность: Плавные 60-120 FPS переходы, визуальный отклик кнопок при нажатии на экране смартфона.

--------------------------------------------------------------------------------
3. АРХИТЕКТУРА И ТЕХНИЧЕСКИЙ СТЕК
--------------------------------------------------------------------------------
- ФОРМАТ: 100% автономный PWA (Progressive Web App). Приложение работает в браузере смартфона (Safari / Chrome) и устанавливается на рабочий стол смартфона в один клик как нативная программа.
- ОФФЛАЙН-РЕЖИМ (Offline-First): В подвалах новостроек и бетонных монолитах Ташкента часто нет интернета. Приложение ДОЛЖНО работать на 100% БЕЗ сети.
- ХРАНИЛИЩЕ ДАННЫХ: Локальная база данных в браузере (IndexedDB + LocalStorage). Все объекты, фото, чеки и сметы хранятся прямо в памяти телефона.
- БЕЗОПАСНОСТЬ И БЭКАП: Кнопка «Экспорт резервной копии» в 1 файл JSON/ZIP, который Улугбек может скинуть себе в Избранное в Telegram, чтобы никогда не потерять данные при смене телефона.
- ГЕНЕРАТОР PDF: Встроенная легковесная библиотека (jsPDF + html2canvas) для создания красивых PDF-документов прямо внутри телефона без отправки данных на сторонние серверы.

4. МОДУЛЬНАЯ СТРУКТУРА ПРИЛОЖЕНИЯ (7 КЛЮЧЕВЫХ ОРГАНОВ)
--------------------------------------------------------------------------------

МОДУЛЬ 1: РЕЕСТР ЭЛИТНЫХ ОБЪЕКТОВ (SITE CARDS)
- Карточка каждого объекта: «ЖК Mirabad Avenue, 4-комн.», «Nest One, Пентхаус», «Коттедж Кибрай».
- Поля: Имя заказчика + телефон (кнопка «Позвонить» / «Написать в TG» в 1 клик), Имя дизайнера + телефон.
- Статус объекта переключается одной кнопкой:
  [1. Аудит проекта] -> [2. Черновой монтаж] -> [3. Опрессовка 16 бар] -> [4. Чистовая сантехника] -> [5. Объект сдан].

МОДУЛЬ 2: КАРМАННЫЙ ФИНАНСОВЫЙ ДИРЕКТОР (CASHFLOW)
- Фиксация договоренностей в 3 клика:
  * Общая сумма работ по договору (например: 15 000 000 сум)
  * Аванс получен (дата, способ: нал / карта)
  * ОСТАТОК ДОЛГА КЛИЕНТА (крупная золотая цифра, которую Улугбек видит сразу)
- Расчеты с подмастерьями/бригадой:
  * Список помощников (напр. «Алишер», «Сардор»)
  * Сколько начислено за объект, сколько уже выдано на руки, сколько мастер должен доплатить.
- Партнерские 10% дизайнеру:
  * Статус: «Начислено» / «Выплачено» / «Передано в виде скидки клиенту».

МОДУЛЬ 3: СНАБЖЕНИЕ, МАТЕРИАЛЫ И ЧЕКИ С БАЗАРОВ (BOM & RECEIPTS)
- Список материалов по категориям с чекбоксами (Куплено / Требуется докупить):
  * Трубы и фитинги: Rehau Rautitan Pink/His / Stout
  * Коллекторы: FAR / Oventrop / Stout
  * Инсталляции и трапы: Geberit Duofix / TECE
  * Защита от протечек: Нептун / Gidrolock
- Фотофиксация чеков: Нажал кнопку «Сфоткать чек» -> фото с камеры телефона прикрепляется к смете объекта. Сумма чека автоматически суммируется с расходами объекта.

МОДУЛЬ 4: ГЛАВНЫЙ ФЛАГМАН — ГЕНЕРАТОР ИСПОЛНИТЕЛЬНОГО ИНЖЕНЕРНОГО ПАСПОРТА (PDF ENGINE)
- Это инструмент, который создает безупречный WOW-эффект и отстраивает Улугбека от всех конкурентов.
- Как это работает для Улугбека:
  1. Выбирает объект.
  2. Загружает/фотографирует прямо в приложении:
     - Фото узла ввода и коллекторов с манометрами
     - 4-6 фото скрытых трасс в стенах и в полу с приложенной лазерной рулеткой (привязка до миллиметра к углам стен)
     - Фото манометра гидропресса на отметке 16 атмосфер (Акт опрессовки)
  3. Нажимает ОДНУ БОЛЬШУЮ ЗОЛОТУЮ КНОПКУ: «СФОРМИРОВАТЬ ИСПОЛНИТЕЛЬНЫЙ ПАСПОРТ (PDF)».
  4. Программа моментально генерирует ламинируемого качества документ формата А4:
     - Фирменная обложка с золотым гербом «Лига Опытных Мастеров»
     - Паспорт объекта с адресом, датой и именами автора проекта и мастера
     - Официальный протокол гидравлических испытаний (Опрессовка 16 бар, тест х4, 24 часа)
     - Галерея фотопривязок с линейными размерами и предупреждением для мебельщиков: «Внимание! Сверление стен производить строго по исполнительным размерам данного паспорта»
     - Юридическая гарантия 2 года с факсимиле подписи мастера
  5. Кнопка «Отправить в Telegram заказчику и дизайнеру».

МОДУЛЬ 5: ЭКСПРЕСС-КАЛЬКУЛЯТОР СМЕТЫ ЗА 60 СЕКУНД
- Крупные кнопки-счетчики:
  * Кол-во санузлов (+ / -)
  * Кол-во точек водоснабжения (+ / -)
  * Инсталляции Geberit (+ / -)
  * Скрытые смесители iBox (+ / -)
  * Трапы в пол (+ / -)
  * Теплый пол (кв.м)
- Мгновенный расчет вилки стоимости работ (от ... до ...) в сумах и долларах с возможностью скопировать смету в виде аккуратного красивого сообщения в Telegram.

МОДУЛЬ 6: КОНТРОЛЬ БРИГАДЫ И ЧЕК-ЛИСТЫ КАЧЕСТВА
- 10 железных пунктов перед заливкой стяжки:
  [ ] Уклоны канализации выверены по лазеру (2 см на метр)?
  [ ] Выводы заглушены металлическими опрессовочными пробками?
  [ ] Шумоизоляция стояка выполнена?
  [ ] Опрессовка 16 бар выдержана 24 часа?
  [ ] Мусор убран строительным пылесосом?
- Подмастерье ставит галочки -> Улугбек видит 100% готовность объекта к сдаче.

МОДУЛЬ 7: АНАЛИТИЧЕСКИЙ РАДАР И СВЯЗЬ С МАРКЕТИНГОМ
- Мониторинг входящих запросов от дизайнеров.
- Статистика заработка за месяц и за сезон 2026.
- Быстрые ссылки на внешние инструменты: Лендинг (liga-masterov.vercel.app), 3D-визитка (vizitka-liga-masterov.vercel.app), чат Telegram.
