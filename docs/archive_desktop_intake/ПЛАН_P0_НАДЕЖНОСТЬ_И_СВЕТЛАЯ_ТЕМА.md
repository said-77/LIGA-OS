# План реализации P0: Доведение LIGA OS до премиального стандарта надежности

## Контекст и цели
На основе независимого аудита GPT и требований владельца по безопасности данных составлен исчерпывающий инженерный план устранения недочетов и перехода от стадии «сильный прототип» к «надежный рабочий продукт премиум-уровня».

---

## 1. Решение вопроса безопасности и восстановления данных (по запросу владельца)
**Проблема**: если Улугбек потеряет телефон, данные в локальной IndexedDB пропадут. Внешние платные сервисы (Supabase, Firebase) создают риски (абонентская плата, засыпание бесплатных инстансов, блокировки).  
**Решение: Гибридная модель «Local-First + Личный Telegram-архив»**:
1. **Экспорт резервной копии в 1 клик**:
   - Кнопка «💾 Сохранить резервную копию в Telegram (Избранное)» или скачивание защищенного файла `.liga_backup`.
   - Файл содержит полный снимок: объекты, сметы, чеки, фото, акты и журнал.
2. **Восстановление на новом устройстве с валидатором**:
   - При выборе файла система не "слепо" перезаписывает базу, а проверяет сигнатуру, дату создания, количество объектов и чеков.
   - Показывается модальное окно: *«Резервная копия от 20.09.2026. Объектов: 3, Чеков: 18. Восстановить?»*.
   - Перед перезаписью создается аварийный откат текущих данных.
3. **Нулевая стоимость**: 100% бесплатно, навсегда, без привязки карт и без внешних серверов.

## 2. Реализация критического блока P0

### P0-1: Исправление формулы сметы (Включение санузлов)
- **Проблема**: параметр `bathrooms` (санузлы) изменяется в UI, но отсутствует в формуле расчета `totalMin`.
- **Исправление**:
  - В инженерной сантехнике каждый санузел требует монтажа распределительного коллекторного узла (ШРН), узлов ввода и стояков.
  - Добавляется базовая ставка на узел санузла (`costPerBathroomNode = 1 500 000 сум`).
  - Формула:  
    `totalMin = (e.bathrooms * costPerBathroomNode) + (e.waterPoints * costPerPoint) + (e.geberit * costPerGeberit) + (e.ibox * costPerIbox) + (e.drains * costPerDrain) + (e.floorHeatingSqM * costPerSqMFloor) + baseAuditWork`.
  - Все коэффициенты выносятся в понятный прозрачный конфиг, открытый для настройки.

### P0-2: Честность и валидность Инженерного Паспорта объекта
- **Проблема**: паспорт открывается как страница печати и автоматически пишет «16 бар пройдено, 24 часа без падения», даже если испытаний не было.
- **Исправление**:
  - Кнопка честно переименовывается: **«Печать / Экспорт в PDF»**.
  - Вводится статус готовности документа:
    - **«ЧЕРНОВИК / ИСПЫТАНИЯ НЕ ЗАФИКСИРОВАНЫ»** — если в чек-листе объекта нет подтвержденной опрессовки и нет прикрепленного фото манометра.
    - **«ОФИЦИАЛЬНЫЙ АКТ ОПРЕССОВКИ ВЫДЕРЖАН»** — только если мастер внес реальные показания манометра (дата, время старта, время финиша, фактическое давление 16 бар) и прикрепил фото.

### P0-3: Отдельный «Клиентский режим» (Client Presentation Mode)
- **Проблема**: показ экрана заказчику или дизайнеру сейчас раскрывает внутренние данные (долги помощникам, закупочные цены базара, черновые пометки).
- **Исправление**:
  - Переключатель в шапке: **«👔 Клиентский показ»** / **«🛠️ Кабина мастера»**.
  - В клиентском режиме скрываются: долги бригаде, себестоимость материалов с базара, внутренние заметки.
  - Отображаются: статус объекта, этапы работ, согласованная смета, фото выполненных узлов, гарантийные обязательства, регламент опрессовки.

### P0-4: Честность сетевых и технологических статусов
- **Проблема**: заявление «100% офлайн» некорректно, если Web Speech API или Telegram требуют интернет. «AI-аудитор» назван искусственным интеллектом, хотя это локальные экспертные правила.
- **Исправление**:
  - В шапке четкий индикатор: **«Оффлайн-база активна»** + пометка у микрофона и Telegram: *(требуется интернет)*.
  - «AI-Аналитик» честно переименован в **«Инженерный аудит объекта (экспертные правила)»**.

### P0-5: Светлая тема с глубоким контрастом под солнце Ташкента
- Полноценная светлая тема (Light Mode):
  - Фон: `#F8FAFC` / чистая светлая керамика `#FFFFFF`.
  - Основной текст: глубокий угольный `#0F172A` (максимальная читаемость на ярком солнце).
  - Карточки: контур `#CBD5E1`, легкие тени без мыльного блюра.
  - Золотые акценты: благородная темная бронза/золото `#9A6A1D` (высокий контраст на белом).
  - Переключатель темы `☀️ / 🌙` в шапке с сохранением в `localStorage`.

## 3. План верификации
1. **Тест формулы сметы**: автоматическая проверка изменения санузлов от 1 до 5 с проверкой корректного пересчета суммы.
2. **Тест честности паспорта**: проверка появления бейджа «ЧЕРНОВИК», пока нет данных опрессовки.
3. **Тест клиентского режима**: проверка скрытия финансовых долгов бригады.
4. **Тест бэкапа**: создание тестового JSON-файла резервной копии, проверка валидатора и восстановление базы.
