# Чек-лист безопасности и конфиденциальности данных (SECURITY_CHECKLIST.md)

> [!IMPORTANT]
> Данный чек-лист является обязательным стандартом при проектировании и внедрении любых внешних сетевых интеграций в системе LIGA OS.

---

## 1. Защита коммерческой тайны и персональных данных заказчиков

- [x] **Изоляция в «Режиме показа клиенту»**:
  - Полное отсутствие в DOM начислений бригаде, оптовых цен базара Джами и товарных чеков при передаче экрана клиенту.
- [ ] **Клиентское шифрование перед отправкой в облако**:
  - Все объекты, адреса ЖК, телефоны клиентов, финансовые проводки и фотографии шифруются на устройстве с помощью алгоритма AES-GCM 256 до отправки в сеть.
- [ ] **Zero-Knowledge Architecture**:
  - Ни облачный провайдер (Supabase), ни разработчики не имеют доступа к содержимому базы данных мастера без его личного мастер-пароля.

---

## 2. Безопасность API-ключей и учетных записей

- [ ] **Строгое разграничение ключей Supabase**:
  - В клиентском приложении используется ТОЛЬКО публичный ключ `anon_key` с включенными политиками RLS (Row Level Security).
  - **Категорический запрет**: секретный ключ `service_role_key` НИКОГДА не должен попадать в репозиторий Git, исходный код PWA или файлы JavaScript!
- [ ] **Аутентификация по протоколу OAuth / JWT**:
  - Сессионные токены хранятся в защищенном локальном хранилище браузера;
  - Срок жизни сессии ограничен, предусмотрен автоматический refresh токена.
- [ ] **Защита от утечек через Git**:
  - Файлы конфигураций с реальными ключами (`.env`, `.env.local`) внесены в `.gitignore`.

---

## 3. Целостность локальных и резервных данных

- [x] **Валидация резервных копий**:
  - Проверка сигнатуры `appName === 'LIGA OS'` и `schemaVersion >= 1`.
  - Реляционная проверка связей `siteId` перед импортом.
  - Автоматическое создание точки восстановления и откат при любых ошибках транзакции.
- [x] **Бескомпромиссная офлайн-устойчивость**:
  - Приложение полностью загружается и функционирует без доступа к сети Интернет.
- [ ] **Запрет тихого затирания (No Silent Overwrite)**:
  - При конфликте версий между облаком и локальной базой мастер всегда получает диалог выбора с возможностью сохранить обе версии.
